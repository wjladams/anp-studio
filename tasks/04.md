# A SuperDecisions.com equivalent UI

The goal is to get a UI that allows us to:
1. Create new networks with subnetworks.
2. Create clusters and nodes
3. Create node -> node connections (which will create node -> cluster and cluster -> cluster connections)
4. Pairwise compare Nodes wrt to parent Node
5. Pairwise compare Clusters wrt to parent Cluster
6. Calculate the unscaled and scaled supermatrix
7. Calculate the limit matrix
8. Synthesize the alternative scores for networks without subnetworks and for those with subnetworks as well.
9. Define the formula for network synthesis to use the standard formulas
10. Save the network (and subnetworks) to a file
11. Read the network from a file.
12. Make use of qt 6.0 undo / redo functionality
