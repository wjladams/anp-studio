Structure — connection UX options

Options for issue #3: making and removing Structure connections that are easy to manage and easy for a new user to find. Click a tab to compare. Colors are illustrative; the live app keeps its existing Structure chrome.

Today: create only via Network/context “Connect Mode” (two node clicks), then mode exits. No remove UI — links aren’t selectable, Inspector Connections is read-only, and DisconnectNodesCmd exists but is unused.
Most discoverable for new users

A — Inspector Connections checklist

Keep the canvas visual. Turn the existing Inspector Connections section into the primary editor: checkboxes by cluster for destinations of the selected node, plus Add / Remove.

  • Pros: uses a panel users already open; add and remove in one place; no hidden mode
  • Cons: less “drawing” on the canvas; large networks need search/filter

Interaction

  • Select a node → Inspector lists possible targets by cluster
  • Check = connect, uncheck = disconnect (undoable)
  • Optional: “Connect to…” search for distant nodes
  • Canvas still shows arrows; optional highlight on hover in list

B — Drag wires on the canvas

Add connection ports on nodes. Drag from a port to another node to create a link. Click an arrow to select it; Delete / Backspace or a context menu removes it.

  • Pros: visual and spatial; add and remove without leaving the canvas
  • Cons: harder on dense layouts; needs careful hit-testing and rubber-band conflict

Interaction

  • Hover node → show ports
  • Drag port → dashed preview → drop on target
  • Click link → highlight; Delete disconnects
  • Right-click link → Disconnect

C — Visible Connect / Disconnect toolbar

Keep click-to-connect, but put tools on a Structure toolstrip so newcomers find them. Add Disconnect mode (click a link, or click source then dest). Status hint guides each step; Escape cancels; mode can stay on for multiple links.

  • Pros: small code delta from current path; fixes discoverability and removal
  • Cons: still a mode; less direct than checkboxes or drag

Interaction

  • Toolstrip: Select · Connect · Disconnect
  • Connect: pick source → dest; hint updates; stays on until Escape
  • Disconnect: click link, or two nodes that are connected
  • Network menu / shortcuts mirror the tools

D — Connection manager sheet

A dedicated “Manage connections…” dialog or bottom sheet lists every From → To pair. Add via two dropdowns; remove with a row button. Reachable from Network menu, canvas empty-space menu, and Inspector.

  • Pros: easy to audit the whole network; great for cleanup; searchable
  • Cons: one step removed from the canvas; less spatial

Interaction

  • Open manager from Network → Manage Connections…
  • Optional filter by source cluster / node
  • Add row: From combo + To combo + Add
  • ✕ on a row disconnects with undo

E — Rich context menus

Right-click a node for Connect to… / Disconnect from… submenus of other nodes (grouped by cluster). Right-click a link for Disconnect. No persistent Connect Mode required.

  • Pros: no mode to learn; remove is obvious on the link; works with keyboard focus later
  • Cons: submenus grow with network size; less visible than a toolbar or inspector

Interaction

  • Node menu: Connect to → cluster → node
  • Node menu: Disconnect from → existing targets
  • Link menu: Disconnect this link
  • Optional: “Connect From Here…” still seeds a one-shot click
