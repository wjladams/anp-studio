  • Empty roster keeps today’s single-judge UX

Q2 · Bulk multi-user input

3 — Import / Export Hub

Actions off Judgments / Session — not a separate stage. Excel always available; live Forms only when that provider is connected in Settings. CSV import works without OAuth.

  • Export/import Excel for one participant
  • Create survey → share URL; import responses
  • Disabled cards nudge Connect in Settings

  • CSV path always on

Analysis + Researcher

4 — Network + Scope

Both Analysis and Researcher keep the existing network chooser and add a participant scope beside it. Network = which subnet; Scope = whose judgments (overall / individual / custom group).

  • Same dual bar on Analysis and Researcher
  • Scope is shared with Judgments Session (always; no sync button)
  • Changing network does not reset scope (and vice versa)

  • Scope: Executives (Alice + Bob)

Q4 · Variance / cohort

5 — Consensus / Variance View

  • Heat on pairwise cells = high variance across users
  • Coverage grid = who filled what
  • Cohort bars = Executives vs Ops priorities

Q5 · Forms OAuth

Settings — Connected accounts

App-level (not per model). Authenticate once; Import/Export Hub only offers live Google/Microsoft create/import when connected. Excel and CSV never need this.

  • Browser OAuth → tokens in OS keychain
  • If not connected, Hub shows Connect… on that card
  • Connecting at Hub time still lands here (persist, not one-shot)

On this mock

  • Google linked as alice@…
  • Microsoft disconnected
  • Separate from Participants Roster
