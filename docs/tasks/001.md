# Updates to the "Synthesis" tab

## Overal Goal
I want the Synthesis tab to become the "Analysis" tab and have several options analyses available.  In order to accomplish this, I want to redesign that page.  The goal is to have all possible ANP related calculations available immediately on that page without showing a popup.

# The Changes
* Title of that panel is now "Analysis"
* Left and right panels in Analysis are no longer necessary.
* On the top left where we have "Network", beside that should be a dropdown to choose the network to perform the analysis shown upon.  Networks should be named "Root" for the toplevel, and then "Root / Benefits" for the Benefits subnetwork, using the "/" as the separator between subnetworks.
* The "Formula" choice (Additive/Multiplicative/Custom) is a setting of a network, not an Analysis result.  That choice should appear in the "Inspector" panel in the "Structure" page.
* I want to have several different Analysis subpanels in this panel, by using a left side tabs structure.  The sub-panels should be:
  * Synthesis: This sub-panel should show the full synthesis chain for the selected network.  Show it as html rendered text, using <h1>'s for titles.  The sections in that html should be:
    * Unscaled Supermatrix: Showing the unscaled supermatrix as an html table
    * Cluster matrix: Showing the cluster matrix
    * Scaled Supermatrix: Showing the scaled supermatrix
    * Global priorities: The global priorities vector
    * Subnetwork synthesis results: If there are subnetworks, show a table whose columns are the subnetworks, whose first row is the normalized (adding to 1) priorities of those nodes with subenetworks from the global priorities, and the remaining rows are the alterantives with their scores from their subnetworks.  Notice, this only looks at the subnetworks of the selected network, nothing further down.
    * Alternative Scores: The resulting alternative scores.  If there are subnetworks, we do the priority weighted average of the subnetwork sysnthesis results.  If there are no subnetworks this is the normalized global priorities of the alternatives.
* Sensitivity: This is ANP Row Sensitivity, there are several expired patents with William Adams as an inventor for Decision Lens, covering this calculation that you can review to find the details.  There are 2 subcases for the actual interactivity
    * Interactive: In this case the user chooses the Wrt Node and there is a slider between 0 and 1 changing the parameter p from the definition of ANP Row Sensitivity.  The results shown should be a horizontal bar chart of the synthesized alternative scores for the selected network with the given ANP Row Sensitivity Change.
    * Global: In this case the user selects the Wrt Node as before, but instead of a slider, we move the parameter p from 0.01 to 1.00 in increments of 0.01 and synthesize using the ANP Row Sensitivity method.  This results in synthesized alternative scores at each p level for the alternatives.  I want to graph those scores as a line chart where the x axis is the p value, the y-axis is the score and there is one series for each alternative, showing the alternative score changing as p changes.
* Influence: These should be the influence analyses described in several expired patents by William Adams for Decision Lens.  For all of these calculations we use p=0.5 for the "resting" parameter value, i.e. the parameter value that gives us the original supermatrix.  There needs to be a selector for each of these where you choose the WrtNode for the calculation, and it should be powered on the selected network from this panel.
    * Raw: In this case a fixed delta is applied to p upwards and downwards, that should be changeable input that defaults to 0.1 and 0.1 downwards. The calculation involves setting p to the new upward value, resynthesizing and then calculating the difference.  Likewise for the downward value.  The result is a matrix whose rows are the alternatives, the first column is the original scores, the second is the upward changing score (should show as NEW_SCORE [Difference] to N decimal places that is a choosable parameter), and the 3rd column is the downward changing score similarly reported.  The table should be sortable on each column.
    * Rank: This should calculate the Rank Influence score according to the patent.  The results should be a table with rows alternatives, and 1st column is the Original Score, 2nd column is the rank influence score.  It should be sortable on all columns.
    * Marginal: This shoudl calculate the marginal influence score from that patent.
