Ratings UX — options C and D

Sketches for simplifying Judgments ratings while keeping the right panel as resulting priorities. Option D shipped in the app (preset-first Scale, Advanced popout, My scales in AppData). This file remains a design archive.

Constraint: do not put scale definition in the right panel — that stays priority bars. Issue #7. Presets split into Built-in (shipped) and My scales (user-added).
Votes first

C — Scale as setup sheet

Center is only voting. Active scale shows as a short summary with Edit scale…. Scale definition (presets + custom) lives in a modal sheet — not in the priorities column.

  • Pros: quiet main surface; presets fit cleanly in the sheet
  • Cons: one extra click to change the scale

What moves

  • Mode / categories / interpreter → Edit scale sheet
  • Votes stay center (dropdowns by label)
  • Priorities stay right

Growing the catalog

C — Pick from library

Edit scale opens a searchable library. Built-in presets ship with the app; My scales are ones you (or your team) added. Selecting one previews categories; Apply binds that scale to this link.

  • Add more later = more cards under Built-in or My scales
  • Search keeps a long list usable

How you add more

  • Ship new Built-in entries in the product
  • User: Save as preset… (see next tab)
  • Optional later: import preset JSON

User-authored presets

C — Save as preset

From a custom scale (or after tweaking a built-in), Save as preset… names it and adds it under My scales. That is the main “add more” path for end users without shipping code.

Flow

  • Edit categories / values on Custom
  • Save as preset → name + optional description
  • Appears under My scales for every ratings link

Preset as primary control

D — Preset menu (expanded)

Scale dropdown lists Built-in and My scales, plus actions to grow the library: Save current as preset…, Manage scales…, Import…. Votes stay below; priorities stay right.

  • Pros: adding presets is visible next to the control that uses them
  • Cons: long menus need groups + Manage for edit/delete

Add more via

  • New Built-in entries in releases
  • Save current as preset…
  • Manage scales… / Import…

Customize then promote

D — Save from Advanced

Power users expand Advanced, edit Id/Label/Value (or numeric interpreter), then Save as preset… so the next link can pick it from the Scale menu without re-entering categories. Scale edits auto-apply when Advanced is collapsed (no separate Apply button).

Shared with C

  • Same Save as preset dialog
  • Same My scales store
  • Only the chrome differs (inline vs sheet)

Numeric scale config

D — Numeric Advanced

Same shell as categorical Advanced: Scale chooser + right-aligned Advanced. Inside the attached popout, Mode is Numeric — interpreter, constant / knots as needed — then votes are raw numbers (not label dropdowns).

Numeric affordances

  • Interpreter: Identity, Divide by max/constant, Min–max, Piecewise
  • Constant / knot table only when relevant
  • Preset menu can still pick “Percent (0–100)” etc.
